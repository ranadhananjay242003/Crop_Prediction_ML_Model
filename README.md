# Crop Prediction and Equipment Recommendation System

This project presents a machine learning-powered crop prediction model tailored to assist farmers in selecting the most suitable crops based on soil and climatic conditions. In addition, it features a recommendation system for farming equipment, enhancing decision-making through intelligent insights.

## 🧠 Features

- **Crop Prediction Model**:  
  Built using Python with Scikit-learn, Pandas, and NumPy. Trained on curated agricultural datasets containing parameters like soil type, temperature, rainfall, and pH level.

- **Machine Learning Algorithms**:  
  Evaluated models including Random Forest, Gradient Boosting, and Logistic Regression. Final model selected based on accuracy and computational efficiency.

- **Feature Engineering**:  
  Applied data cleaning and transformation techniques to extract meaningful patterns from the raw dataset.

- **Interactive Interface**:  
  Integrated with a front-end interface via FAST APIs allowing users to input location and soil data for real-time crop recommendations.

- **Equipment Recommendation System**:  
  Implemented collaborative filtering based on user activity and historical preferences to suggest relevant farming equipment.

## 🛠 Tech Stack

- **Languages**: Python  
- **Libraries**: Scikit-learn, Pandas, NumPy  
- **APIs**: FAST API  
- **Recommendation System**: Collaborative Filtering (User Behavior Analysis)
